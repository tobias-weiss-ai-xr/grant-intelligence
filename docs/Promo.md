## 3. One-Pager (DIN A4, für Jury-Handout)

### Förder-Radar – Grant Intelligence
*Der persönliche Förder-Assistent für die Philipps-Universität*

**Das Problem**
Forschende verlieren wöchentlich Stunden mit zwei Fragen: „Welche Förderung
passt zu mir?" und „Wann ist Schluss?" Antworten verstecken sich in Portalen,
Mails und Kalendern. Verpasste Fristen bedeuten verpasste Fördermittel –
unbemerkt.

**Die Lösung**
Ein kleiner, selbst aufsetzbarer Assistent, der offizielle, frei lizenzierte
Quellen (DFG, ERC, Bund, Land, Stiftungen) in einer Agent-Schleife –
Aufnahme, Suche, Meldung – zu einem persönlichen Brief verdichtet:
Top-Treffer mit Begründung und Budget, die nächste Frist in Tagen,
Warnungen rechtzeitig.

**Was ihn auszeichnet**

| | |
|---|---|
| **Offen** | Open Source (MIT), Quellcode + Katalog auf GitHub, Mitmachen per Merge Request |
| **Datenschutzfreundlich** | Läuft lokal, keine Cloud-Pflicht, DSGVO-fähige Einwilligung für Profile |
| **Standardbasiert** | Model Context Protocol (MCP) – anbindbar an beliebige KI-Assistenten |
| **Ehrlich** | Nur offizielle Quellen, jede Frist mit Stand-Datum, Scores als Orientierung |
| **Faktenbasiert** | 75 Programme, 9 Kategorien, 138 Tests, 100 % Testabdeckung |

**Der Nutzen**
- Weniger Such- und Abstimmungsaufwand
- Weniger verpasste Fristen
- Eine verständliche Entscheidungsgrundlage

**Der Weg**
Ein Pilot am eigenen Fachbereich – in wenigen Wochen umsetzbar, liefert echte
Kennzahlen als Grundlage für eine wiederkehrende, bezahlte Nutzung. Zuerst in
Marburg, später übertragbar auf andere Hochschulen.

**Mitmachen erwünscht:** beim Pflegen der Quellen, beim Schärfen der
Matching-Regeln, beim ersten gemeinsamen Pilot.
